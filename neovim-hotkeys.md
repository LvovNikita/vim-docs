# Горячие клавиши Neovim + LazyVim

Лидер-клавиша: `Space`
Нажми `Space` и подожди — появится меню с подсказками.

## Файлы и навигация

| Клавиши      | Действие                          |
|--------------|-----------------------------------|
| `Space e`    | дерево файлов (открыть/закрыть)   |
| `Space ff`   | найти файл по имени               |
| `Space fg`   | поиск текста по всему проекту     |
| `Space fr`   | недавние файлы                    |
| `Space ,`    | переключиться между файлами       |

## Код и LSP

| Клавиши      | Действие                          |
|--------------|-----------------------------------|
| `gd`         | перейти к определению             |
| `gr`         | найти все использования           |
| `K`          | документация под курсором         |
| `Space ca`   | code actions (быстрые исправления)|
| `Space cr`   | переименовать символ              |
| `[d` / `]d`  | предыдущая/следующая ошибка       |
| `Space cd`   | показать ошибку под курсором      |

## Git

| Клавиши      | Действие                          |
|--------------|-----------------------------------|
| `Space gg`   | открыть Lazygit                   |
| `Space gb`   | git blame текущей строки          |

## Общее

| Клавиши      | Действие                          |
|--------------|-----------------------------------|
| `Space /`    | закомментировать строку           |
| `Space q`    | закрыть буфер                     |
| `Space ww`   | переключиться между сплитами      |

## Базовые команды Vim

| Клавиши      | Действие                          |
|--------------|-----------------------------------|
| `i`          | режим вставки                     |
| `Esc`        | normal mode                       |
| `:w`         | сохранить                         |
| `:q`         | закрыть                           |
| `:wq`        | сохранить и закрыть               |

## Навигация по строкам

| Клавиши      | Действие                          |
|--------------|-----------------------------------|
| `42G`        | перейти на строку 42              |
| `:42`        | то же самое                       |
| `gg`         | начало файла                      |
| `G`          | конец файла                       |
| `{n}j / {n}k`| прыжок на n строк вниз/вверх     |
