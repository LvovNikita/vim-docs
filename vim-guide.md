# Полный гайд по Vim: для программиста и для редактора текстов

Гайд разбит на блоки: базовые режимы, быстрая навигация, работа с абзацами (важно для редактора текстов), отступы/индентация, перемещение строк и блоков кода, поиск/замена, макросы, и отдельно — настройка LSP и полезные плагины для современной разработки в (Neo)Vim.

Рекомендация на старте: используйте **Neovim** вместо классического Vim. Он полностью совместим по командам и `.vimrc`, но имеет встроенный LSP-клиент, Lua-конфигурацию и активную экосистему плагинов. Дальше в гайде почти всё справедливо для обоих, а специфика Neovim отмечена отдельно.

---

## 1. Режимы Vim (коротко)

| Режим | Вход | Назначение |
|---|---|---|
| Normal | `Esc` | Навигация и команды |
| Insert | `i`, `a`, `o` | Ввод текста |
| Visual | `v`, `V`, `Ctrl-v` | Выделение (посимвольно / построчно / блоком) |
| Command | `:` | Команды `:w`, `:s`, `:m` и т.д. |
| Replace | `R` | Замена символов по мере ввода |

Правило №1 в Vim: **не сидите в Insert-режиме дольше, чем нужно**. Основная сила Vim — в Normal-режиме и в композиции команд «оператор + движение».

## 2. Быстрая навигация по строкам и абзацам

### 2.1 Навигация по строкам

| Команда | Действие |
|---|---|
| `j` / `k` | вниз / вверх на строку |
| `0` | в начало строки (включая пробелы) |
| `^` | в начало строки (первый непробельный символ) |
| `$` | в конец строки |
| `gg` | в начало файла |
| `G` | в конец файла |
| `{число}G` или `:{число}` | перейти на строку N (напр. `42G`) |
| `Ctrl-d` / `Ctrl-u` | прокрутка на пол-экрана вниз/вверх |
| `Ctrl-f` / `Ctrl-b` | прокрутка на экран вперёд/назад |
| `H` / `M` / `L` | курсор в начало/середину/конец видимого экрана |
| `zz` / `zt` / `zb` | центрировать/поднять/опустить текущую строку на экране |

### 2.2 Навигация по словам

| Команда | Действие |
|---|---|
| `w` / `b` | следующее / предыдущее слово (включая знаки пунктуации) |
| `W` / `B` | то же, но по «большим словам» (WORD, разделитель — пробел) |
| `e` / `ge` | конец следующего / конец предыдущего слова |

### 2.3 Навигация по абзацам и предложениям (ключевое для редактора текстов)

| Команда | Действие |
|---|---|
| `{` / `}` | к предыдущему / следующему пустому абзацу (blank line) |
| `(` / `)` | к началу предыдущего / следующего **предложения** |
| `ap` / `ip` | text object: «весь абзац» / «абзац без окружающих пустых строк» (используется с оператором, см. ниже) |
| `as` / `is` | text object: предложение |

Пример: `dap` — удалить весь абзац целиком вместе с пустой строкой после него. `vip` — выделить абзац без пустой строки.

### 2.4 Прыжки и поиск по тексту

| Команда | Действие |
|---|---|
| `f{символ}` / `F{символ}` | прыжок вперёд/назад к символу в строке |
| `t{символ}` / `T{символ}` | прыжок вперёд/назад **до** символа (перед ним) |
| `;` / `,` | повторить / повторить в обратную сторону последний `f`/`t` |
| `/паттерн` + `Enter` | поиск вперёд |
| `?паттерн` + `Enter` | поиск назад |
| `n` / `N` | следующее / предыдущее совпадение |
| `*` / `#` | найти следующее/предыдущее вхождение слова под курсором |
| `%` | прыжок к парной скобке `(){}[]` |
| `Ctrl-o` / `Ctrl-i` | назад / вперёд по истории переходов (jumplist) |
| `` `` (два backtick) `` / `` `` | вернуться к позиции до последнего большого прыжка |
| `ma` затем `` `a `` | поставить метку `a` и прыгнуть к ней |

### 2.5 Экранная (визуальная) навигация — для editors/writers

Для длинных строк без переносов (`textwidth`, prose) полезно:

| Команда | Действие |
|---|---|
| `gj` / `gk` | перемещение по *визуальным* строкам, а не логическим |
| `g_` | конец строки без учёта завершающих пробелов |

## 3. Отступы и выравнивание блоков кода (индентация)

### 3.1 Базовые команды

| Команда | Действие |
|---|---|
| `>>` | увеличить отступ текущей строки на один `shiftwidth` |
| `<<` | уменьшить отступ текущей строки |
| `{число}>>` | отступ для N строк, напр. `5>>` |
| `>ip` | отступ для всего абзаца (оператор + text object) |
| `>%` | отступ для блока в скобках, если курсор на скобке |
| `==` | автоматически переформатировать отступ строки (по правилам языка/filetype) |
| `=ip` / `=G` / `gg=G` | переформатировать отступы абзаца / до конца файла / всего файла |

### 3.2 Через визуальный режим (самый частый способ)

1. Выделить блок: `V` (построчно) или `v` + движение, затем выбрать нужные строки.
2. `>` — увеличить отступ, `<` — уменьшить.
3. После первого `>` нажмите `gv` (повторно выделить последнее выделение), затем `.` или снова `>`, чтобы сдвинуть ещё раз — **или**, что удобнее:

**Важный лайфхак**: в визуальном режиме, чтобы отступ можно было применять несколько раз подряд без выхода из режима, замапьте:

```vim
" в .vimrc / init.vim
vnoremap < <gv
vnoremap > >gv
```

После этого `>` в визуальном режиме не сбрасывает выделение — можно жать `>` несколько раз подряд, чтобы сдвинуть блок сильнее.

### 3.3 Блочное (столбцовое) выделение — Visual Block

`Ctrl-v` — вход в Visual Block mode. Полезно для:
- добавления текста в начало нескольких строк сразу: `Ctrl-v`, выделить нужные строки (только по вертикали, ширину можно не трогать), `I`, ввести текст, `Esc` — текст появится на всех выделенных строках;
- удаления/замены столбца символов (например, номеров строк, отступов конкретной ширины): `Ctrl-v`, выделить столбец, `x` или `c` + текст + `Esc`;
- выравнивания «столбиков» в таблицах или списках.

### 3.4 Настройки отступов (обязательно проверить в конфиге)

```vim
set tabstop=4       " сколько столбцов занимает символ табуляции
set shiftwidth=4    " ширина отступа для >> << и ==
set softtabstop=4   " сколько столбцов "стирает" Backspace/сколько вставляет Tab
set expandtab       " превращать Tab в пробелы (обычно нужно для большинства языков)
set autoindent      " сохранять отступ текущей строки при переходе на новую
set smartindent      " умный отступ для C-подобных языков (для остальных лучше filetype indent)
filetype plugin indent on   " включить indent-плагины под конкретный язык
```

Для точной настройки под каждый язык (Python — 4 пробела, JS/TS — часто 2, Go — табы) используйте `ftplugin` или плагин `editorconfig-vim` / встроенную поддержку `.editorconfig` в Neovim.

## 4. Перемещение строк и блоков кода вверх/вниз

### 4.1 Одна строка — быстрый способ

Самый практичный вариант — смапить `Alt-j` / `Alt-k` (или другие удобные клавиши) на перемещение строки:

```vim
" Normal mode: переместить текущую строку вниз/вверх
nnoremap <A-j> :m .+1<CR>==
nnoremap <A-k> :m .-2<CR>==

" Insert mode
inoremap <A-j> <Esc>:m .+1<CR>==gi
inoremap <A-k> <Esc>:m .-2<CR>==gi

" Visual mode: переместить выделенный блок
vnoremap <A-j> :m '>+1<CR>gv=gv
vnoremap <A-k> :m '<-2<CR>gv=gv
```

Где `:m` (`:move`) — команда перемещения строк, а `==` / `gv=gv` сразу переформатирует отступ на новом месте (важно для кода).

> В macOS Terminal.app и iTerm2 нужно включить передачу Alt как Esc+клавиша (Option as Meta) в настройках терминала, иначе `Alt` не сработает как модификатор.

### 4.2 Без ремапов — стандартными средствами

| Команда | Действие |
|---|---|
| `ddp` | удалить строку и вставить её строкой ниже (эффект — сдвиг вниз на 1) |
| `ddkP` | сдвиг строки вверх на 1 |
| `dd` затем `p`/`P` | вырезать строку и вставить после/до курсора где угодно |
| `:m+1` | сдвинуть текущую строку на 1 вниз |
| `:m-2` | сдвинуть текущую строку на 1 вверх |
| `:5,10m20` | переместить блок строк 5–10 после строки 20 |
| `:5,10m0` | переместить блок строк 5–10 в начало файла |

### 4.3 Перемещение выделенного блока (Visual mode)

1. `V` — выделить нужные строки (можно и несколько сразу, `j`/`k`).
2. `:m '>+1` — сдвинуть блок на строку ниже (после последней выделенной).
3. `:m '<-2` — сдвинуть блок на строку выше (перед первой выделенной).

Vim сам подставит `'<,'>` — метки границ последнего визуального выделения — если вы наберёте `:m` находясь ещё в visual mode (двоеточие само вставит `'<,'>`).

### 4.4 Дублирование строки/блока (часто нужно рядом с перемещением)

| Команда | Действие |
|---|---|
| `yyp` | скопировать строку и вставить копию ниже |
| `yyP` | вставить копию выше |
| `:t.` | дублировать текущую строку (аналог `yyp`, но через ex-команду, удобно с диапазонами: `:5,10t.` ) |
| `:t0` | скопировать текущую строку в начало файла |

## 5. Работа с абзацами и текстом — специфика для редактора (не только кода)

### 5.1 Переформатирование текста (жёсткий/мягкий перенос)

| Команда | Действие |
|---|---|
| `gq` + движение (напр. `gqip`, `gqap`, `gq}`) | переформатировать текст под ширину `textwidth` |
| `gqq` или `gwq` | переформатировать текущую строку/абзац |
| `set textwidth=80` | ширина, под которую `gq` будет переносить строки |
| `gw` | как `gq`, но не двигает курсор |

Это критично для человека, который правит прозу: `set textwidth=80` + `gqap` быстро приводит абзац к красивому виду с переносами по словам.

### 5.2 Опции форматирования (`formatoptions`)

```vim
set formatoptions+=t   " автоперенос обычного текста по textwidth во время ввода
set formatoptions+=q   " разрешить gq форматировать комментарии
set formatoptions-=o   " не продолжать комментарий после 'o'/'O' (по вкусу)
```

### 5.3 Проверка орфографии

```vim
set spell spelllang=ru,en   " включить проверку орфографии на русском и английском
```

| Команда | Действие |
|---|---|
| `]s` / `[s` | следующая / предыдущая орфографическая ошибка |
| `z=` | предложить варианты исправления слова под курсором |
| `zg` | добавить слово в личный словарь (считать правильным) |
| `zw` | пометить слово как неправильное |

### 5.4 Регистр и точечные правки текста

| Команда | Действие |
|---|---|
| `~` | сменить регистр символа под курсором |
| `g~iw` | сменить регистр слова |
| `guiw` / `gUiw` | сделать слово строчным / ПРОПИСНЫМ |
| `g~ap` | сменить регистр всего абзаца |

### 5.5 Полезные text objects (работают с `d`, `c`, `y`, `v`, `>`, `gq` и т.д.)

| Text object | Значение |
|---|---|
| `iw` / `aw` | слово / слово с пробелом |
| `is` / `as` | предложение |
| `ip` / `ap` | абзац |
| `i"` / `a"` | внутри кавычек / с кавычками |
| `i(` `ib` / `a(` `ab` | внутри скобок / со скобками |
| `it` / `at` | внутри HTML/XML тега / с тегом |

Формула Vim: **оператор + text object = действие**. `ci"` — заменить текст внутри кавычек, `dap` — удалить абзац, `yit` — скопировать содержимое тега.

## 6. Поиск и замена, регулярные выражения

```vim
:%s/старое/новое/g        " заменить во всём файле
:%s/старое/новое/gc       " с подтверждением каждой замены
:5,10s/старое/новое/g     " заменить только в диапазоне строк 5–10
:s/старое/новое/g         " заменить только в текущей строке
```

Полезные флаги при подтверждении (`c`): `y` — заменить, `n` — пропустить, `a` — заменить все, `q` — выйти.

Поиск и замена по визуальному выделению: выделите блок `V`, наберите `:` — Vim подставит `:'<,'>`, допишите `s/.../.../g`.

## 7. Макросы — автоматизация повторяющихся правок

```
qa        " начать запись макроса в регистр a
...       " ваши действия
q         " закончить запись
@a        " выполнить макрос a
5@a       " выполнить макрос a 5 раз
@@        " повторить последний выполненный макрос
```

Незаменимо для правки текста/кода, где одна и та же трансформация нужна на десятках строк (например, обернуть каждую строку списка в кавычки и добавить запятую).

## 8. Множественные курсоры / замена по всем вхождениям слова

В Vim нет «множественных курсоров» как в VSCode «из коробки», но есть эквиваленты:
- `*` затем `cgn` + текст + `Esc`, затем `.` — заменить следующее вхождение слова под курсором, повторяя через `.`.
- Плагин **vim-visual-multi** (`mg979/vim-visual-multi`) добавляет полноценные множественные курсоры по Ctrl-n, как в Sublime/VSCode.

## 9. LSP (автодополнение, переход к определению, рефакторинг) — настройка

### 9.1 Neovim (рекомендуемый путь, LSP встроен в редактор)

Минимальный стек:

1. **nvim-lspconfig** — готовые конфиги для большинства языковых серверов.
2. **mason.nvim** + **mason-lspconfig.nvim** — установка и управление языковыми серверами прямо из Neovim (аналог `:LspInstall`).
3. **nvim-cmp** — автодополнение (движок), с источником `cmp-nvim-lsp`.
4. **nvim-treesitter** — точная подсветка синтаксиса и лучший `==`/навигация по коду.

Пример базовой конфигурации на Lua (`~/.config/nvim/init.lua` или отдельный файл, если используете `lazy.nvim` как менеджер плагинов):

```lua
-- через lazy.nvim
require("lazy").setup({
  { "neovim/nvim-lspconfig" },
  { "williamboman/mason.nvim", config = true },
  { "williamboman/mason-lspconfig.nvim" },
  {
    "hrsh7th/nvim-cmp",
    dependencies = { "hrsh7th/cmp-nvim-lsp", "L3MON4D3/LuaSnip" },
  },
  { "nvim-treesitter/nvim-treesitter", build = ":TSUpdate" },
})

require("mason").setup()
require("mason-lspconfig").setup({
  ensure_installed = { "pyright", "tsserver", "gopls", "rust_analyzer", "lua_ls" },
})

local capabilities = require("cmp_nvim_lsp").default_capabilities()

require("mason-lspconfig").setup_handlers({
  function(server_name)
    require("lspconfig")[server_name].setup({ capabilities = capabilities })
  end,
})

local cmp = require("cmp")
cmp.setup({
  mapping = cmp.mapping.preset.insert({
    ["<Tab>"] = cmp.mapping.select_next_item(),
    ["<S-Tab>"] = cmp.mapping.select_prev_item(),
    ["<CR>"] = cmp.mapping.confirm({ select = true }),
  }),
  sources = { { name = "nvim_lsp" } },
})
```

### 9.2 Стандартные LSP-биндинги (после настройки)

| Команда | Действие |
|---|---|
| `gd` | перейти к определению |
| `gD` | перейти к объявлению |
| `gr` | найти все использования (references) |
| `K` | показать документацию/сигнатуру под курсором (hover) |
| `<leader>rn` | переименовать символ (rename) во всём проекте |
| `<leader>ca` | code actions (быстрые исправления, автоимпорты и т.д.) |
| `[d` / `]d` | предыдущая / следующая ошибка диагностики |
| `<leader>f` | форматирование файла через LSP (`vim.lsp.buf.format()`) |

Эти биндинги не встроены по умолчанию — их нужно прописать самому в `on_attach`, например:

```lua
vim.keymap.set("n", "gd", vim.lsp.buf.definition)
vim.keymap.set("n", "gr", vim.lsp.buf.references)
vim.keymap.set("n", "K", vim.lsp.buf.hover)
vim.keymap.set("n", "<leader>rn", vim.lsp.buf.rename)
vim.keymap.set("n", "<leader>ca", vim.lsp.buf.code_action)
vim.keymap.set("n", "[d", vim.diagnostic.goto_prev)
vim.keymap.set("n", "]d", vim.diagnostic.goto_next)
```

### 9.3 Если используется классический Vim (не Neovim)

Классический Vim 9+ тоже поддерживает LSP через плагин, самые популярные варианты:
- **coc.nvim** — несмотря на название, работает и в обычном Vim 8+; эмулирует VSCode-подобный LSP-клиент, ставит серверы через `:CocInstall coc-pyright`, `coc-tsserver`, `coc-go` и т.д.
- **vim-lsp** (prabirshrestha/vim-lsp) — более «ванильный» и легковесный LSP-клиент.
- **ale** (Asynchronous Lint Engine) — линтинг и форматирование (не полноценный LSP, но отлично дополняет).

### 9.4 Другие плагины, которые стоит поставить

| Плагин | Зачем |
|---|---|
| `nvim-telescope/telescope.nvim` | fuzzy-поиск файлов, строк по проекту, LSP-символов |
| `tpope/vim-surround` | быстрая работа с окружающими скобками/кавычками (`cs"'`, `ysiw"`) |
| `tpope/vim-commentary` (или `numToStr/Comment.nvim`) | закомментировать/раскомментировать строку/блок (`gcc`, `gc` в visual) |
| `mg979/vim-visual-multi` | множественные курсоры |
| `lewis6991/gitsigns.nvim` | git-изменения на полях, staging по хункам прямо в редакторе |
| `nvim-tree/nvim-tree.lua` или `neo-tree.nvim` | файловое дерево |
| `folke/which-key.nvim` | подсказки по маппингам, если их много |
| `windwp/nvim-autopairs` | автозакрытие скобок/кавычек |

### 9.5 Полезное для редактора текстов (не кода)

| Плагин | Зачем |
|---|---|
| `preservim/vim-pencil` | режим для прозы: мягкие переносы, sentence-навигация как в текстовых редакторах |

## 10. Компактная шпаргалка (самое важное одним взглядом)

```
НАВИГАЦИЯ
gg / G           начало / конец файла
{число}G         на строку N
{ / }            по абзацам
( / )            по предложениям
Ctrl-d / Ctrl-u  полэкрана вниз/вверх
* / #            искать слово под курсором вперёд/назад

ОТСТУПЫ
>> / <<          отступ строки туда/обратно
gv               восстановить выделение (для повторного > <)
=ip / gg=G       автоформат отступа абзаца / всего файла
Ctrl-v            visual block для столбцовых правок

ПЕРЕМЕЩЕНИЕ СТРОК
:m .+1 / :m .-2  строка вниз / вверх на 1 (с ремапом Alt-j/Alt-k)
ddp / ddkP       строка вниз / вверх (без ремапов)
:m '>+1          сдвинуть visual-блок вниз
:m '<-2          сдвинуть visual-блок вверх

ТЕКСТ / ПРОЗА
gqap             переформатировать абзац по textwidth
]s [s z=         орфография: след./пред. ошибка, варианты
dap / cap / yap  удалить/заменить/скопировать абзац

LSP (Neovim)
gd / gr / K      определение / использования / документация
<leader>rn       переименовать символ
<leader>ca       code action
[d / ]d          диагностика назад/вперёд
```

## 11. Рекомендованный порядок внедрения

1. Освойте навигацию (`hjkl`, `w/b`, `{}`,  `gg/G`, поиск `/`) — без неё остальное бесполезно.
2. Привыкните к формуле «оператор + text object» (`d`, `c`, `y` + `iw/ip/i"` и т.д.) — это ядро эффективности Vim.
3. Настройте отступы (`shiftwidth`, `expandtab`) и ремапы `Alt-j/Alt-k` для перемещения строк — сразу почувствуете разницу.
4. Поставьте Neovim + `lazy.nvim` как менеджер плагинов, дальше добавляйте `nvim-lspconfig` + `mason.nvim` — это закроет 90% потребностей программиста.
5. Для текстовой работы отдельно включите `spell`, `textwidth`, `gq`, и по желанию `vim-pencil`/`goyo`.

Если нужно — могу собрать под вас готовый файл конфигурации (`init.lua` для Neovim или `.vimrc` для классического Vim) под конкретный стек языков/задач.
